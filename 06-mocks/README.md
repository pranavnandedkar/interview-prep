# 06 — Mock Interview Loops

## Weekly loop

### Mock 1 — System Design
45–60 minutes.

### Mock 2 — Architecture Leadership
30–45 minutes.

### Mock 3 — Coding
45–50 minutes.

### Mock 4 — Resume / Behavioral
45 minutes.

## Scoring dimensions

Do not reduce performance to a single score. Capture evidence under:
- requirements clarity
- scale reasoning
- architecture
- distributed-systems depth
- trade-offs
- failure handling
- communication
- influence
- ownership
- coding quality

## Final 5-minute review

After each mock write:
- What did I miss?
- Where did I hand-wave?
- Which trade-off was weak?
- Which question surprised me?
- What should become a reusable story?

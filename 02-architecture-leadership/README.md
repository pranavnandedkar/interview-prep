# 02 — Architecture & Technical Leadership

This section targets the Senior Staff distinction: not only designing systems, but creating technical direction across teams.

## Topics

- RFC writing
- Architecture review boards
- Technical strategy
- Influence without authority
- Platform adoption
- Migration strategy
- Build vs buy
- Standardization vs team autonomy
- Cost / reliability trade-offs
- Organizational boundaries
- Architecture decision records
- Measuring adoption and outcomes

## RFC interview template

For every major architecture decision, prepare:

1. Problem and business context
2. Constraints
3. Current-state limitations
4. Options considered
5. Decision
6. Why alternatives were rejected
7. Stakeholders and disagreements
8. How alignment was achieved
9. Migration / rollout
10. Metrics
11. Result
12. What you would change today

## Key Senior Staff question

"Tell me about an architecture decision where the technically obvious solution was not enough."

The answer should demonstrate technical reasoning plus organizational execution.

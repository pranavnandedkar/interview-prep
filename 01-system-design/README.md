# 01 — System Design

## Core exercises

### Priority A
- Real-Time Profile Store
- Centralized Decisioning Platform
- Customer Identity Resolution

### Priority B
- Enterprise Kafka Platform
- Customer Data Platform / real-time segmentation
- Search / typeahead platform
- Agentic / LLM platform

### Supporting designs
- Rate limiter
- Notification / frequency-cap system
- Distributed scheduler
- Distributed lock with auto-expiration
- Feature flag service
- Event-driven audit platform

## Required format for each design

Every design should contain:
1. Problem statement
2. Clarifying questions
3. Functional requirements
4. Non-functional requirements
5. Capacity estimates
6. API design
7. Data model
8. High-level architecture
9. Detailed component design
10. Partitioning and scaling
11. Consistency and concurrency
12. Failure modes
13. Observability
14. Security/privacy
15. Cost
16. Multi-region strategy
17. Alternatives and trade-offs
18. Evolution
19. Staff-level follow-up questions
20. 2-minute closing summary

Target interview time: 45–60 minutes.

# 04 — Coding

## Target

Be able to solve practical medium-level problems cleanly in Java in roughly 35–45 minutes while explaining design decisions.

## Priority patterns

1. HashMap + frequency
2. Sliding window
3. Intervals
4. Heap / priority queue
5. BFS / DFS
6. Topological sort
7. Binary search
8. Graph shortest path
9. Producer/consumer
10. Thread-safe cache
11. TTL / expiration
12. Rate limiter
13. Scheduler
14. Concurrent data structure

## Interview behavior

For every problem:
- clarify assumptions
- state approach before coding
- name invariants
- write readable Java
- test normal and edge cases
- state time/space complexity
- discuss concurrency if relevant
- discuss production extensions if the problem is infrastructure-oriented
